# Changelog

## 1.0.0

First open-source release.

- Character creation: picture, name, path, emblem, theme, plan length, vocabulary.
- Splash screen with your avatar, level and rank.
- Game layer: XP, levels, ranks, unlock cards, level-up screen, 28 trophies, optional sound. Can be switched off.
- Six themes (including a light theme), banners, emblems, living background.
- Inventory, Quests, Roadmap (any plan length), Atlas (editable), Journal, Experience, Profile, Now with starter quests.
- Rename every tab and term; Game / Academic / Plain vocabularies; hide tabs.
- Several profiles per browser.
- Content packs: YAML authoring, schema validation, import, and upgrades that keep progress.
- Backups with attachments; optional folder sync (Chrome/Edge).
- Ships with no content: only the Blank map.
